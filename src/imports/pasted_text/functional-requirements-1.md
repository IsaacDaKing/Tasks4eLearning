2.1 Functional Requirements
2.1.1 User Interface & System Redesign
FR-01: The system shall display a customizable dashboard showing pinned courses and upcoming deadlines.
FR-02: The interface shall allow users to toggle between "Light mode" and "Dark mode" themes.
FR-03: Users shall be able to search for content across all enrolled courses from a global search bar.
FR-04: Users shall be able to collapse the left-hand course navigation menu to maximize screen space.
FR-05: The interface shall include a "Quick Poll" feature for instructors to gauge student comprehension live.
FR-06: The system shall provide a "What's New" changelog pop-up after major interface updates.
FR-07: Users shall be able to customize keyboard shortcuts for frequent actions (e.g., Save, Submit).
FR-08: Users shall be able to "pin" important announcements to the top of their dashboard for quick reference.
FR-09: The system shall provide a "Focus Mode" that hides non-essential widgets during quiz taking.
FR-10: The system shall provide a "Quiet Hours" setting where users can mute all non-critical notifications during specified time blocks.
FR-41: The system shall remove nested pop-up windows.
FR-42: Opening classes, assignments, and grades shall load as separate full pages.
FR-29: Instructors shall be able to create anonymous discussion boards to encourage student participation.
FR-30: The system shall support embedded multimedia annotations (e.g., comment on specific timestamps of a video).
FR-31: Students shall be able to flag inappropriate discussion posts for moderator review.
FR-35: Students shall be able to annotate lecture slides directly in the browser with private notes that persist across sessions.
2.1.2 Assessment & Gradebook Features
FR-11: Instructors shall be able to drag-and-drop files from their desktop directly into the module uploader.
FR-12: The system shall auto-save assignment submissions locally every 30 seconds to prevent data loss.
FR-13: Students shall be able to view their grade distribution compared to the class average anonymously.
FR-14: Instructors shall be able to create peer review assignments with automatic random reviewer allocation.
FR-15: Instructors shall be able to set conditional availability: students must complete Item A to unlock Item B.
FR-16: The system shall allow instructors to reuse course content from previous semesters via a cloning tool.
FR-17: Students shall be able to submit assignment extension requests with digital signatures.
FR-18: The system shall provide a "Compare Documents" view showing side-by-side differences between a student's draft and final submission.
FR-44: Students shall be able to modify projected assignment scores in a simulation mode.
FR-45: The system shall calculate projected final course grades.
FR-46: The system shall generate temporary cumulative GPA calculations.
FR-53: Users shall be able to pin/unpin specific tools to the sidebar navigation menu, showing only selected favorites while hiding others.
2.1.3 AI-Powered Student Success Assistant & Analytics
FR-21: Instructors shall be able to view analytics on which students have viewed specific course materials.
FR-22: The system shall generate automated weekly progress summaries sent via email to students.
FR-23: Students shall be able to generate a "Study Plan" playlist that curates uncompleted assignments and suggested review materials based on upcoming deadlines.
FR-25: Instructors shall be able to create customizable badges/awards that students can earn for meeting specific milestones.
FR-26: Students shall receive push notifications for new assignment postings and grading feedback.
FR-27: Instructors shall be able to generate printable rosters with student photos.
FR-28: Instructors shall be able to create interactive "Choose Your Own Adventure" style branching modules for scenario-based learning.
FR-48: The system shall send predictive alerts for at-risk students.
FR-49: The system shall suggest time management strategies.
2.1.4 Accessibility Features
FR-43: The system shall allow dyslexia-friendly fonts options.
FR-50: The system shall allow font resizing.
FR-51: The system shall support high-contrast modes.
FR-52: The system shall support screen readers and caption integrations.
FR-32: The system shall provide a text-to-speech option for reading assignment descriptions.
FR-36: The system shall automatically generate alt-text suggestions for uploaded images, allowing instructor confirmation before publishing.
2.1.5 Administration, System Integration, Security & Maintenance
FR-38: Administrators shall be able to bulk-enroll users via CSV upload.
FR-39: Students shall be able to form study groups and share private files within the group space.
FR-40: The system shall integrate with Zoom to display live class recordings directly in the course page.
FR-19: Users shall be able to log in using Single Sign-On (SSO) with their institutional credentials.
FR-33: Users shall be able to report technical bugs directly from the help menu with auto-captured screenshots.
FR-34: The system shall support offline access to downloaded course materials via a mobile app.
FR-54: The system shall maintain a comprehensive audit log of all grade changes, including: timestamp, user ID, previous value, new value, and IP address; accessible to administrators with appropriate permissions.
FR-63: The system shall support a forgot/reset password functionality..
FR-64: The system shall support a remember credentials functionality.
2.1.6 Assignments & Assessments
FR-55: The system shall display the Course Code and Course Name (e.g., ENVI 301) prominently at the top of the assignment page.
FR-56: The system shall display the module title as the primary heading of the module page.
FR-57: The system shall provide dedicated fields for Due Date and Class displayed in a distinct header section for high visibility for all module pages.
FR-58: The system shall allow instructors to use a Rich Text Editor to create module instructions, including support for bold text, italics, and bulleted lists.
FR-59: The system shall allow instructors to define a specific "Requirements" subsection within the instructions to highlight technical constraints (e.g., page count, citation style).
FR-60: The interface shall feature a primary "Submit Assignment" button that remains disabled until a valid file has been attached.
FR-61: The system shall for assessments clearly state if it is a quiz or exam.
FR-62: The system shall for assessments clearly state time limit and number of attempts.
